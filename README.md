# Own tests

Run from root: `python tests/test_solution.py`. See ANALYSIS.md for independent expected-answer explanations, scale generation, alternative and invalid witnesses and route results. `expected.json` contains inputs and expected semantic fields; `actual.jsonl` contains three mixed batches, while `my_cases.jsonl` contains one batch. Order/labels/forest witnesses are checked semantically using the supplied checker. Full-limit inputs are generated by the script rather than stored. Run `python tests/benchmark.py` to reproduce the benchmark protocol; the saved measurements describe the original execution environment. Public results were produced by `python tools/run.py --check`.
